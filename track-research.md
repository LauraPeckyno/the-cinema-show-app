## Audio Approach
Since we cannot download audio from SoundCloud directly, we will:
- Stream audio from SoundCloud using their embed/widget API
- Use the SoundCloud Widget API to control playback
- The ambient microphone audio will be processed locally using Web Audio API concepts via expo-audio
- BPM sync and effects will be applied to the microphone samples
